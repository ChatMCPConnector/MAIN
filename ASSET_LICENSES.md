# Asset and audio licenses

## Game visuals

No external game assets are included. All fighters, enemies, backgrounds, interface elements, effects, projectiles, props, pickups, and icons are drawn at runtime from Godot primitives by `game/main.gd`. The original source code and procedural designs are covered by this repository's MIT license.

## Audio

No external audio files are included. Menu, movement, attack, hit, block, pickup, special, victory, and music tones are synthesized at runtime from simple waveforms by `game/main.gd` and are covered by the repository's MIT license.

## Little Fighter 2 review

No Little Fighter 2 files are used. The project does not copy its names, characters, graphics, sound effects, music, stages, code, data, or branding. Only broad genre ideas—side-view depth movement, quick group combat, local multiplayer, and special attacks—inform the gameplay structure.

## Engine

Godot Engine is MIT licensed by the Godot Engine contributors. The exported runtime includes the engine license notice through `LICENSES.txt` and this document. Refer to the official Godot repository for full contributor copyright information.
